# Game2 v0.6.0-dev — 人物轻量演出

## 已实现
- 为吴婶与陈站长增加独立的头部、手部运动枢轴。
- 站立时有克制的呼吸/轻微转头；问话期间增加点头和手部细微运动。
- 对话结束后自动恢复待机状态；切换场景时清理对话状态。
- 无新增素材授权依赖；角色外观沿用上一轮原创程序化低模。
- 自动测试检查两名人物枢轴、对话演出开启与关闭。

## 制作边界
这属于**程序化占位演出**，没有正式骨骼绑定、动作捕捉、面部表情或角色配音。当前只改善站桩感，尚不能替代最终的半写实角色制作。

## 下一步
- 为案件中的关键录音设计镜头语言、音频和互动节奏。
- 制作可复用的半写实人物资产与角色材质。
- 加入可在 Windows 实机执行的画面截图验收。

## 本轮补充：问话构图与真实画面截图

- 宽度至少 1100px 的窗口中，将证人对话面板放在右侧，使吴婶或陈站长仍能留在玩家视线内；较窄窗口与所有非问话面板仍然居中并支持滚动。
- F12 截取当前游戏**真实渲染画面**，PNG 写到 Godot 的用户目录 `screenshots` 文件夹。界面左下角显示绝对路径或写入错误。
- 保留并行已合并的 PR #9 人物动作实现，避免引入第二套运动脚本。
- CI 测试覆盖右侧问话面板状态与截图文件名。Headless CI **不能验证截图实际画质**，仍需 Windows 实机按 F12 获取图像。

### 玩家实机检查

启动 Windows 游戏，走近 NPC 并与其对话，观察 NPC 在面板旁的动作；按 F12 检查真实 PNG。建议分别检查街道、广播站、祠堂以及首次听到磁带之后的场景。
