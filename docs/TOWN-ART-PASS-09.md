# Game2 v0.9 · 怀声镇主街视觉纵切片

## 目标
把玩家第一眼看到的镇中心从早期“方块 + 重复噪声贴图”改善为具有 2003 年县镇生活痕迹、冷暖层次和可辨认建筑的独立布景。

## 已实现
- 采用独立 `scripts/town_set.gd`，原主街方块楼、抽象浮动黄色海报、重复临街饰物不再叠加。
- 双侧不同高度的旧楼，灰泥 / 金属墙面 / 青绿色墙裙、真实层次的窗框、窗台、金属卷帘、雨棚、雨水管和檐口。
- 吉祥小卖部与县广播站专属门面，走近可区分店铺、旧广播站和值班室。
- 重构寻人启事的双柱木质布告栏与纸面；公用电话机、木箱和折旧道路设施。
- 减少新式虚线道路视觉，用不规则路面修补、路缘石、井盖、排水沟和积水细节代替。
- 原创电线杆与多段下垂电缆、钠灯、冷暖分区照明；街道独有的蓝灰色黄昏背景与轻雾。
- 延续 v0.8 原创 CPU 生成的颜色、粗糙度、法线纹理，复用材质缓存，避免重复引入第三方视觉资产。
- 保留所有原有证据、电话异象、小卖部 / 广播站 / 祠堂入口热点的 ID 与坐标，兼容现有存档。
- 旧广播站 v0.8 视觉纵切片不回退；这轮不修改其他室内场景。
- 新增街道布景与材质、时间线异象测试；Godot 自动实际渲染截图从 7 张增加到 9 张，新增小卖部外观与广播站外观的近景固定机位。

## 画面验收与边界
- 统一对比 `01_street.png`（同一视角、分辨率 1280×720）及 `07_haunted_street.png` 的异变前后层次。
- 新的 `08_shopfront.png` 与 `09_radio_exterior.png` 检查店面近景是否穿模、遮挡招牌、影响准星调查与门口路线。
- Linux X11/Mesa 上截取真实 Godot 图像仅能证明原型在该环境能渲染；Windows 实机性能和玩法路径仍需单独手动检查。
- 这些美术仍是代码生成的过渡资源，不等同于授权 PBR 扫描、专业建模、实体烘焙或商业宣传素材。
- 下一步应针对任意房屋建立真实门窗建模/遮挡正确的网格与可编辑 GLB 素材管线，并加入漫反射、反射及动态天色视觉验收。
