# v0.20「证据之间」大版本计划

基线：18e052b1f806a03440ea75d7b601bc3ba02f2710（v0.14.0-dev）。2026-11-17。

## 目标与范围

让调查从收集后直接选答案，扩展到调查 → 出示材料追问 → 选择证据建立关联 → 形成有限结论 → 回看未解疑点。保持第一人称民俗悬疑、原四线索门槛、全部场景、旧证据 ID 和安全存档机制。美术仍为过渡资产，本轮不宣称最终美术、完整失踪案结局或 Steam Demo。

| 系统 | 本轮交付 | 验收 |
| --- | --- | --- |
| 关联板 | 五条独立问题，选择两份已收集证据，再作推断；错配不授予结论 | 缺材料、重复材料、错误配对、错误推断、取消与正确提交 |
| 证据追问 | 吴婶/陈站长各两条条件追问，材料不足不可访问 | 四条追问实际 GUI、证词入档、原问话镜头退出 |
| 调查卷宗 | 主线、身份、声音来源和停播顺序的证据边界；完成后继续调查 | 空档不泄露、完成档可回看、旧档恢复、新结论持久化 |
| 调查线索页 | 按已发现材料提示地点/人物，不提前公开时间或超自然结论 | 空档与完整档状态、小窗口滚动、键盘导航 |
| 发布证据 | 既有全套测试、新增玩法回归、实际渲染、Windows 构建和 EXE 存档回归 | 精确提交的 Actions 状态；未执行项明确标注 |

## 内容边界

五条关联依次处理传播先后、账本身份、练声记录的证明限度、停播通知时序、民俗与异常之间的证明限度。后四项为可选深化，不反向锁住已完成的旧档。每条结论保存为稳定证据 ID；中途选择仅保留在面板中，关闭后重选，不产生半份存档。

已知时间：2003-07-17 21:10 失踪告示、21:47 内线录音、22:16 全镇播报；学校 20:30/20:43；正式停播通知 7 月 18 日。不能以声音/姓名证明本人，不能以练声簿或民俗残页证明超自然来源。

## 交付顺序

1. 独立内容/规则模块与状态门槛。
2. 关联板、证据追问、线索页、卷宗接入。
3. 失败路径/存档兼容测试与输入驱动回归。
4. 实际画面观察、修正、CI、合并与构建分发。

后续方向（不计入本轮完成）：正式人物与场景资产、真人配音、声音来源的后续案件、实体 Windows 试玩及性能预算。
