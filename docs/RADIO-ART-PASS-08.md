# Game2 · 广播站视觉纵切片（v0.8.0-dev）

## 本次动手重做

先对一间房间负责，避免以更多功能掩盖画面品质问题。重建旧广播站的室内比例和美术层次，不动原有案件逻辑和存档格式。

- **建筑体量**：12m × 12m 的室内、降低天花高度至约 4m；木地板、磨损地毯、墙裙、木制踢脚线、吊顶钢梁、门框、百叶窗、散热器和管线
- **磁带与广播设备**：双盘开盘录音机（实体盘面、转轴和磁头）、带扫描线的 CRT 监听屏、调音台（推子与 VU 表）、旧式磁带档案架、值班记录、停播通知与时钟
- **光照和构图**：降低室内太阳光与基础环境光；冷色荧光灯作为环境主光，磁带机上方以暖色工作灯形成焦点，左窗有少量冷光补光。首次播放磁带后保留异常红光提示
- **材质**：全新代码绘制的 128×128 颜色纹理、粗糙度、切线空间法线纹理；按木、灰泥、钢、黄铜、纸、布料、塑胶等分类，并复用材质缓存
- **可玩性**：保留 `log`、`tape`、`broadcast_notice`、`npc_radio`、`exit` 五个热点，保留原有录音演出和对话
- **自动验证**：Godot CI 检查新美术场景与 PBR 通道、室内灯光、热点。截图工作流生成真实 Godot 画面，可比较前后变化

## 品质边界

**这仍是完整的程序化视觉纵切片，属于可运行的中间美术版本。** 虽然设备立体结构、明暗和颜色控制比原先的灰盒更完整，但尚未提供由专业美术制作的真实拓扑网格、写实材质扫描、真实软阴影 GI、角色动作和正式美术资产。不能宣称达到最终半写实品质，也不应把 CI 的无错误等同于真人试玩验收。

## 真实画面验收标准

1. 同一镜头下，旧版广播站的大块灰墙与单一桌面应被可辨认的录音机、调音台、CRT、档案架等取代。
2. 冷暖光分区应清晰：磁带机是视觉中心，同时环境角落仍能看见道具。
3. `tests/capture_visuals.gd` 的第 04 张广播站截图为统一取景，且新版本严格通过 Godot 导入、case01 和视觉截图 CI。
4. Windows 真实运行仍需检查 GPU 差异、按 E 调查热点、角色站位、穿模、遮挡与性能。
5. 如果新版本仍然显得廉价，应继续迭代原创模型/外部合法授权资产，而非继续堆剧情系统。
