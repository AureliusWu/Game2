# Game2 Iteration 03 — 《广播里的人》证词与材质升级 (v0.3.0-dev)

## 范围
- 从纯色几何灰盒向有表面变化的模块化环境前进一步：为建筑外墙、路面、室内地砖、屋顶等赋予可重复的**程序化材质**。增加粗糙度和少量金属度。所有纹理由代码确定性生成。
- 新增两位静态低模占位人物：小卖部吴婶、旧广播站陈站长。当前仅供交互定位，不含最终角色美术、骨骼、表情或配音。
- 调查菜单新增两个话题，每人一条可归档的**关键证词**，另一条背景问话。
- 证词用于检验事件解释：账本上出现林小禾名字不等于她本人出现；21:47 是监听设备内录音，而不是 22:16 的全镇广播。
- 旧主线的 4 条必要证据、时间线推理、结局、存档方式不变。问话属于可选深挖：双证词齐全时尾声会补充证据判断。
- 新测试覆盖 NPC 热点、证词收集、存档与证词不得替代原始物证的规则。

## 对玩家
1. 在小卖部找柜台侧方的吴婶，按 E 对话。分别询问账本和当年敲门。
2. 在广播站找控制台附近的陈站长，询问录音来源和停播通知。
3. 按 J 重新打开笔记，找到两条证词。此时尚不能直接通关，仍须找到四条指定时间线证据。
4. 结合笔记完成已有推理，观察有无双证词时尾声的不同细节。

## 视觉边界
- **不是最终半写实 PBR 建筑**。目前为程序生成色彩变化、粗糙度、少量金属度与基础灯光。它改善纯色材质的塑料感，但没有专业扫描贴图、法线图、完整 UV、原创建筑模型、动画。
- 民俗禁忌“封声”及“听山的”为世界观中的虚构内容。
- 不复刻受版权保护的歌曲、商标、具体品牌广告。
- 正式美术验收仍需 Windows 实机截图、分辨率/性能检查及 20 分钟试玩。
