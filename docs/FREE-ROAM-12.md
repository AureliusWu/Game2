# 第十二轮：自由走位、问话构图与实体交互

版本：`0.12.0-dev`。起点：`f5df91b`（v0.11）。

## 触发问题与本轮计划

用户提供的 Windows 画面暴露了此前固定路线验收的盲区：贴近陈站长时沿用玩家视角，右侧问话面板遮住人物，人物比例显得失控，背景广播站招牌部分文字藏进墙面。

| 优先级 | 可复现问题 | 本轮执行 |
| --- | --- | --- |
| P0 | 距离、方向、窗口尺寸变化后，问话面板挡脸 | 独立可恢复的问话镜头，检查障碍物；宽屏保留人物区域，窄屏改为底部面板 |
| P0 | 可穿过证人和部分大件，近距离视角穿模 | 证人胶囊碰撞；档案架、柜子、椅子、货架、告示板、电话柜补碰撞；验证实际通路 |
| P1 | 招牌随视角转动，文字切入墙面 | 按墙面朝向固定文字；账本、日志、祠堂残页文字贴到纸面 |
| P1 | 长问话退出不便，小窗口仍采用宽屏布局 | 标题与关闭按钮固定，正文滚动；布局跟随真实窗口尺寸，支持问话中途缩放 |
| P1 | 祠堂线索与出口依赖漂浮字和发光方块 | 独立 ShrineSet，实物残页桌、无名牌位与返回街道的门；统一热点锚点 |
| P1 | 验收只覆盖既定路线 | 补多角度镜头、物理碰撞、界面生命周期与真实渲染回归，保留完整输入试玩 |

## 实际行为

- 问话镜头不移动玩家身体。按接近方向选择约 2.6 米的镜头位置，检查路径、最终位置和看向人物的视线，短过渡后把人物与面板分开。角色会转向当前镜头。
- 关闭问话、打开普通面板、切换区域及退出时恢复相机原来的局部变换和视角。反复问同一人不覆盖最初保存的视角，中途改变尺寸会重新取景。
- 1100 像素以上采用右侧最多 420 像素的面板；较窄窗口使用底部面板。标题、关闭按钮固定在滚动区域之外，原有 Tab / 方向键 / Enter 操作保留。
- NPC 自身碰撞体允许被交互射线命中，其他墙体仍能遮挡，避免补碰撞后反而无法问话。
- 街道两处入口门牌移到雨棚前沿的实体牌面，避免正常街面视角下第一行名称被雨棚遮住；原有外观截图同时覆盖这项修复。
- 人物比例调整，移除悬浮姓名；尚未查看账本或录音时，问题使用自然询问，不提前说出未知证据的日期或时间。
- 祠堂取消旧房间、室内路灯、漂浮残页字和热点发光方块的叠加。供桌、残页桌、柱子、长凳有实体，室内使用低太阳光与局部冷暖光。三个热点均对准可见物件。
- 从店铺和广播站回到街道时朝向道路。标题栏显示 `v0.12.0-dev`，便于辨别下载版本。

证据 ID、存档路径和核心时间事实保持兼容：2003 年 7 月 17 日 21:10 失踪、21:47 内线录音、22:16 全镇播报。

## 验证范围与证据

环境：官方 Godot 4.7.2，Linux，X11 与 Mesa llvmpipe 软件渲染。所有 QA 使用隔离或禁用的存档。

1. 导入、`smoke.gd`、`case01.gd`、`exploration.gd`、`player_ux.gd` 通过。探索回归现覆盖 17 处可见接近位置，包括祠堂真实出口。
2. `free_roam.gd`：两名证人、8 个方向、近/远两种距离、4 种分辨率和不同 FOV，排除本来就站在家具内部的无效位置后，验证 100 组构图。检查头部完整投影不与面板相交、身体不移动、视角准确恢复；另检查问话中途缩放、关闭按钮、菜单/区域切换、人物/设备实体碰撞及通道通行。
3. `capture_free_roam.gd`：10 张实际帧缓冲截图，包含报告中的 2048×1074 近距离构图、正侧后方问话、800×600 与 640×360 小窗口、问话中途缩放、墙面招牌、祠堂残页与出口。
4. `capture_visuals.gd`：保留 13 张原有场景/界面实渲染图，等待镜头过渡完成后截图。
5. `player_journey.gd`：通过 WASD、鼠标视角、E/J/H/Esc 与 Tab/Enter 连续取证、问话、听录音、核对账本、纠正错误推理、结案、取消与确认重开。本地完整路线约 159.0 米，保留 16 个阶段截图及 `journey.json`。新增人物/架子碰撞后，路线通过侧通道绕行，不能再借穿模直达。

CI 增加自由走位断言和 10 张专项截图，Windows 导出依赖全部逻辑回归通过。工件分别为 `Game2-Windows-x64`、`Game2-Free-Roam-Regression`、`Game2-Actual-Render-Screenshots`、`Game2-Player-Journey`。

## 验收边界

这些是 AI 输入驱动的流程验证、物理/UI 断言与真实引擎截图。没有把它们等同于 Windows 人工自由试玩或真实显卡性能验收。路线覆盖当前首案，未证明任意走位与任意硬件都没有问题。

角色和场景依然使用原创程序化过渡美术；本轮改善比例、摆放、碰撞与可读性，未完成正式角色模型、骨骼动画、表情或真人配音。正式资产替换仍是后续制作工作。
