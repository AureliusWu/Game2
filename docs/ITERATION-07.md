# Game2 v0.7.0-dev · 21:47 录音互动演出

## 本轮交付
- 旧广播站的 21:47 录音由一段文字弹窗升级为四段可推进的**交互式监听**：磁带起转、内线接通、异常语句、录音结束；标注时间码和当前监听进度。
- 屏幕显示剧本化的文字转录和可见音频波形条，音效为游戏运行时生成的磁带电机、噪声、电波载频、停转声。**没有合成/录制真实人声，也未加入第三方音乐或配音。**
- 播放至最后才将“21:47 的录音”记录为关键证据、保存游戏并触发小镇的环境异变。允许跳过演出直接记录证据，避免强制重复观看。
- 允许随时退出；中断监听不会提前给出证据，也不会让视觉异变永久生效。已完成的录音可以再次复听。
- 原有吴婶、陈站长问话、推理、F12 真实截图、Windows 构建流程保留。
- CI 追加录音四段顺序、中途退出、不提前发放线索、生成的音频内容、复听保留线索等测试。

## 可玩流程
1. 进广播站找到 21:47 的磁带，按 E。
2. 点击“按下播放键”，沿 4 段声画信息逐步点击“继续监听”；在最后一段“记录线索并结束”。
3. 听到异常声音的文字转录，获得「磁带证据」，环境光照出现变化。
4. 返回街道，触发一次性广播回声，并按 J 整理 21:47 → 22:16 的时间链。
5. 再次播放录音时可以复听或跳过，笔记证据不丢失。

## 美术与 QA 边界
- 实现的是文字、轻量波形 UI、环境参数变化、原创合成音效组成的**原型级演出**，当前不包含电影化镜头轨迹、角色口型、人声演技、专业混音或高品质动画资产。
- Godot 严格 CI 能查出脚本错误与状态机问题，不能代替 Windows 实机画面和听感验收。F12 依然可在运行时保存真实截图。
- 继续保持虚构的「封声」「听山的」民俗设定，避免误称真实历史习俗。
