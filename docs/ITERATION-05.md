# Game2 v0.5.0-dev — 角色视觉识别

## 本轮实现
- 将吴婶与陈站长从通用圆柱人替换为两套原创程序化低多边形角色，包含头部、头发、外套、四肢、鞋和身份标识。
- 吴婶：旧式围裙、盘起的头发、绿色开衫；陈站长：旧制服、眼镜、领带和胸牌。
- 保留既有对话、调查、存档和时间线推理。
- Godot headless 测试确认角色节点存在且构成完整。

## 明确限制
- 当前角色仍为低多边形程序化模型，没有骨骼、表情、动作捕捉、正式材质或配音。
- 这一步解决角色辨识度，不能等同于完成半写实人物美术。
- Windows 实机画面、遮挡、视线和碰撞仍需人工试玩。
