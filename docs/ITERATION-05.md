# Game2 v0.5.0-dev · 镇小学与证词互证

## 设计目标
将《广播里的人》从单纯时间差选择题向可玩的推理案件推进，但不增加战斗、追逐或复杂系统。继续采用第一人称、2000 年代地方生活、梦核/民俗志怪和克制的宇宙未知。

## 新增场景：怀声镇小学
- 从主街右侧的旧校舍入口进入。场景采用原创程序化课桌、黑板、教室通知、教员桌、墙面材料与灯光，仍是过渡灰盒艺术，不等于正式 PBR 3D 美术。
- 校务交接簿：2003 年 7 月 17 日，暑期播音训练于 20:30 结束；老师 20:43 记载林小禾离校；21:10 镇里开始寻人。解决“暑期为什么还在学校、深夜放学”的逻辑缺口。
- 练声簿：记录林小禾对录音回声的个人描述，只是线索，不能被当作已证实的超自然事实。
- 教室有程序化的风扇和荧光灯音色；听过 21:47 的磁带后黑板上会出现额外文字。

## 可选互证
玩家集齐校务交接簿、小卖部赊账记录及吴婶证词后，可在 J 调查笔记中进入『对照账本与人证』。玩家需要判断：账本写有林小禾姓名，能否说明她本人回来过？只有听声记名，没有任何目击。正确结论将添加『证据互证：名字与目击』，保存到本地进度，并在尾声附加一段人性层面的推理；错误推理不丢失进度。

**核心四条证据仍是**寻人启事、账本、广播站值班日志、21:47 录音。玩家即使不调查学校，也能完成第一案原有时间线推理。额外的互证有意允许玩家区分 *听说/姓名记录* 与 *实际目击*，让超自然层保持未知。

## 验收
自动测试检查：校舍入口和两条线索、两名既有证人证词、不正确互证不可获得结果、正确互证写入存档、支线不能绕过主线四证据、传统正确与错误答案、声音与静态资源加载。
GitHub Actions 同时检查 Godot 4.7.2 导入、脚本运行错误，生成 Windows x64 构建工件。自动化**不能**证明 Windows 实机界面可读、走位顺畅、材质美观或满足 Steam Demo 标准。
