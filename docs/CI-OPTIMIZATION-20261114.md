# CI 优化与审查漏项修复

- 三个作业统一调用 `.github/actions/setup-godot`，固定官方 Godot 4.7.2。编辑器按 OS/架构/版本缓存，命中后仍校验版本；Windows 模板独立缓存，只提取 Windows 目标文件和版本标识。
- 工具保存在 runner 临时目录，避免下载包进入游戏工程或构建产物。运行依赖、导入数据与测试结果不缓存。
- 两个工作流对同一 PR 的过时运行自动取消，主分支和手动验证继续完整执行。
- 逻辑、导出和实渲染失败均保留日志工件；原错误匹配、成功标记、所有逻辑/存档/连续试玩及 Windows 构建门禁保留。
- 复核 PR #18 发现账本标题仍低于纸面及装饰线，已抬到所有不透明表面上方；新增基于实际网格表面高度的回归检查和一张实际渲染近景。自由走位截图由 10 张增至 11 张。

新缓存首次运行仍需正常下载，实际加速幅度须由后续命中运行测量。缓存命中和绿色工作流均不能替代 Windows 人工试玩或正式美术验收。
