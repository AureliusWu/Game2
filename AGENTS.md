# Game2 contributor instructions

- Godot 4.7.2 stable; GDScript; no C# requirement. Keep Windows x64 the priority.
- Maintain the identity in docs/CASE01.md: first-person 3D Chinese folk-horror mystery with millennium nostalgia and dreamcore unease.
- The experience is investigation > interview > deduction > consequence. Do not add combat, forced chase, crafting, or photography magic without a separate design decision.
- Keep story facts internally consistent. The broadcast was 22:16; the earlier tape was 21:47; the missing poster is 21:10, July 17, 2003.
- Run Godot import and tests/smoke.gd before marking PR green; keep GitHub Actions working.
- Prefer small scenes and explicit evidence IDs over giant monolithic systems. Keep objects swappable for future PBR replacement.
- Never claim graybox assets are final semi-realistic art or that headless smoke proves gameplay quality.
- No external game/music assets without clear redistribution license.
- User interface language is simplified Chinese; project docs can be bilingual.
