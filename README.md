# Game2 · 旧梦乡（工作代号）

Chinese folk horror · millennium nostalgia · dreamcore · cosmic mystery

第一人称 3D 民俗志怪推理游戏。首个案件：**《广播里的人》**。当前是可交互的 **Godot 灰盒原型**；美术和音效尚未达到最终半写实品质，暂非 Steam Demo。

## 当前进度（v0.5.0-dev）

- **学校场景**：主街新增怀声镇小学的可探索教室，配有课桌、黑板、校务交接簿与林小禾练声簿。
- **时间线**：2003 年 7 月 17 日暑期播音训练 20:30 结束、20:43 登记离校、21:10 寻人启事、21:47 内线磁带、22:16 全镇广播，事件脉络更清晰。
- **可选证据互证**：在 J 笔记中结合小学记录、小卖部账本和吴婶证词，证明「账本上的姓名不等于失踪者本人出现」。正确判断被存档并扩展结局。
- **核心玩法不加复杂度**：四条关键证据仍可直接完成原有第一案推理。没有新增战斗、追逐、背包或超能力。
- **环境声音**：为校舍新增程序化电扇和旧荧光灯音景；旧磁带后教室出现文字异样。
- **自动验收**：包含校舍进入、支线条件、证据判读、保存和原主线回归测试。完整流程仍需 Windows 实机试玩验收。

详细记录：[第五轮开发说明](docs/ITERATION-05.md)。

## 第四轮进度（v0.4.0-dev）

- **交互修复**：调查热点改为准星瞄准 + 距离限制 + 静态物理遮挡检查，避免隔墙取证。
- **小镇建筑**：临街建筑的模块化窗框、窗台、立面装饰真正布置在外墙上，修复早期装饰藏在建筑体内的问题。
- **叙事演出**：首次听完 21:47 录音并回到街上，触发一次广播异常，记录到笔记；公用电话可在前后阶段提供不同内容。
- **UI/调查**：增加当前调查目标提示、适配窗口尺寸的对话面板、证人多轮连续问话操作。
- **测试**：新增瞄准、额外线索、电话前后状态、回街异象的自动测试。

详细记录：[第四轮开发日志](docs/ITERATION-04.md)。

## 第三轮进度（v0.3.0-dev）

- **画面层次**：新增可重复使用的程序化粗糙墙面、地砖、木质、金属和水泥贴图与基础材质参数；仍是过渡场景材质，并非完成的半写实 PBR 资产。
- **人物问话**：小卖部吴婶与广播站陈站长；各 2 个可询问话题，静态占位人形模型。
- **证词推理**：新增吴婶、陈站长的可收集证词。账本署名不等于本人到场，21:47 录音不等于 22:16 全镇播报。
- **笔记与结局**：证词存档、笔记展示；完整调查两人可解锁尾声的补充解释。
- **验证**：CI 检查证人热点、可选证词存档与主线四证据的推理门槛。

详细记录：[第三轮开发日志](docs/ITERATION-03.md)。

## 第二轮进度（v0.2.0-dev）

- **环境细节**：小镇增添电话亭、电线杆、广告牌与旧屋立面；小卖部增加 CRT 收款设备、饮料货架、挂历；广播站有磁带设备和停播通知；祠堂增加香火、牌位和封声禁忌。
- **环境声音**：运行时合成虫鸣、电器嗡鸣、收音机干扰和祠堂风声，无第三方音频版权依赖。
- **演出变化**：首次听到 21:47 录音后，雾气、光照与镇上文字出现轻微异常。
- **可选调查**：新增三条民俗/年代线索；推理依然围绕四条关键证据展开。
- **易读性**：长文本和推理面板支持滚动；CI 增加场景、音频、异常与逻辑检查。
- **下载**：在 GitHub Actions 对应成功运行的 Artifacts 中获取 Game2-Windows-x64，PR 可直接提供候选构建。

详细记录：[第二轮开发日志](docs/ITERATION-02.md)。

## 第一轮实现（v0.1.0-dev）

- 怀声镇 3D 主街道、旧小卖部、广播站、祠堂：使用引擎内程序化几何搭建，可探索与切换区域。
- 第一人称 WASD / Shift、鼠标观察、E/F 交互、J 调查笔记、Esc 鼠标与界面管理。
- 5 条剧情线索、4 条必要证据、一次以 21:47 / 22:16 时间矛盾为核心的推理。
- 错误推理反馈、尾声、存档到 user://case01-save.json。
- GitHub Actions：Godot 导入检查、场景 smoke、主分支 Windows x64 构建工件。

## 运行

1. 下载 [Godot 4.7.2 Standard](https://godotengine.org/download/)，无需 .NET 版。
2. 使用 Godot 项目管理器打开本仓库的 project.godot。
3. 点击右上角运行项目（F6/F5，推荐 F5）。
4. 进入小镇并依次调查：镇入口寻人启事、小卖部账本、广播站日志和录音。打开 J 笔记开始推理。

Godot 也支持在命令行运行：

    godot --path .

CI 冒烟测试：

    godot --headless --editor --path . --import
    godot --headless --path . --script res://tests/smoke.gd
