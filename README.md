# Game2 · 旧梦乡（工作代号）

Chinese folk horror · millennium nostalgia · dreamcore · cosmic mystery

第一人称 3D 民俗志怪推理游戏。首个案件：**《广播里的人》**。当前是可交互的 **Godot 灰盒原型**；美术和音效尚未达到最终半写实品质，暂非 Steam Demo。

## 第九轮进度（v0.9.0-dev · 怀声镇街道视觉纵切片）

- **整条主街重做**：独立 `TownSet` 街景取代旧方块建筑堆叠，加入各具比例的县镇旧楼、小卖部与广播站外立面、磨损雨棚、卷帘门、窗棂与年代招牌。
- **街头年代细节**：木质寻人布告栏、公用电话、凹凸修补路面、排水沟、积水、电杆和自然下垂电线。
- **灯光与材质**：蓝灰黄昏、钠灯/室内冷光并置；复用上一轮缓存颜色、粗糙度、法线贴图；异变后增添独立的失声广播视觉节点。
- **功能回归**：保留全部五个街道交互热点 ID；寻人告示栏与对应调查点移动到路边，既有存档和其他场景逻辑不变。
- **截图验收**：真实 Godot 自动截图由 7 张增至 9 张，包含两个外观近景。同机位核验画面差异。
- **仍为过渡美术**：尚无写实扫描材质或正式商业级建筑模型。

详情：[第九轮主街美术日志](docs/TOWN-ART-PASS-09.md)。

## 第八轮进度（v0.8.0-dev · 广播站视觉纵切片）

- **重做旧广播站室内美术**：用独立的录音室场景取代单桌子灰盒；低天花、木地板/墙裙、声学墙、窗帘、档案、旧设备、CRT、实体双盘磁带机等。
- **原创 PBR 通道**：新的按品类缓存的程序化颜色、粗糙度、法线纹理；替换过去明显重复的灰墙贴图，突出真实物件形态。
- **光照重构**：广播站使用室内专属的冷色荧光灯、暖色工作灯和局部窗光，压低户外太阳光。
- **玩法兼容**：保持全部关键证据、人物问话、录音四阶段演出与存档；新增美术与灯光回归测试。
- **边界**：这是一间房间的原创程序化美术提升，不是全地图完成专业写实 PBR，也不是 Steam 可发布 Demo。

详情：[广播站视觉纵切片验收要求](docs/RADIO-ART-PASS-08.md)。

## 第七轮进度（v0.7.0-dev）

- **线索与存档**：只有完整结束或选择跳过演出时才将磁带证据归档；中断不提前解锁，成功后仍可复听。
- **逻辑回归**：测试覆盖录音进度、音效、退出/重播、线索门槛与既有推理流程。
- **仍是原型**：没有真人配音、电影级镜头动画、正式 PBR 人物/场景资产品质。

记录：[第七轮开发日志](docs/ITERATION-07.md)。

## 运行

1. 下载 [Godot 4.7.2 Standard](https://godotengine.org/download/)，无需 .NET 版。
2. 使用 Godot 项目管理器打开本仓库的 project.godot。
3. 点击右上角运行项目（F6/F5，推荐 F5）。
4. 进入小镇并依次调查：镇入口寻人启事、小卖部账本、广播站日志和录音。打开 J 笔记开始推理。

Godot 也支持在命令行运行：

    godot --path .

CI 冒烟测试：

    godot --headless --editor --path . --import
    godot --headless --path . --script res://tests/smoke.gd

## 目录

- docs/CASE01.md — 剧情、设计边界、里程碑
- .github/workflows/godot.yml — 自动验证与 Windows 构建
