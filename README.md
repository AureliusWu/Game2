# Game2 · 旧梦乡 (working title)

A Chinese folklore mystery / millennium-era dreamcore first-person 3D investigation game.

This repository is being initialized for a Godot 4.7.2 prototype of Case 01: 广播里的人.

Design focus: explore, question, collect evidence, deduce. No combat and no mandatory jump scares.

See docs/ for the scenario and milestone notes once the prototype branch lands.
